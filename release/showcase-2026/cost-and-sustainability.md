## Cadence after the showcase

The run is complete and the deployment is inert. `attention-sink-production-cycle` is
`DISABLED` and the run-cycle function's `AS_EXECUTION_ENABLED` is `false`. Both switches
have to be on for a cycle to happen, and neither turns itself on, so the deployment makes
no model calls and costs only storage — under two cents a month at the rates above.

There is no plan to resume this run. It is frozen: resuming would produce a different run
under the same protocol, which is a different artefact and would be labelled as one.

## Cost controls that were active during the run

- Six writer calls per cycle and 600 per run, checked before every call. 316 cycle calls
  were spent against that ceiling.
- Reserved concurrency of 1 on the run-cycle function, 100 on the read API.
- A CloudWatch alarm on the model-call limit, and one on abnormal token use.
- Everything deploys with execution and schedule disabled, in all three environments.
